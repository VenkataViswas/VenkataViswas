I'm a **Data Science postgraduate student at GITAM University** passionate about engineering intelligent, secure, and scalable AI applications.

I enjoy designing systems where LLMs do more than generate text — they retrieve relevant information, reason through workflows, validate outputs, and recover from unreliable results.

> ✏️ **Don't just make AI generate answers. Build systems that retrieve, validate, improve, and deliver useful results.**

**What I enjoy building:**

- 🧠 Agentic AI systems with LangGraph and LangChain
- 🔎 RAG applications with retrieval evaluation and self-correction
- 📊 Natural Language to SQL systems for conversational analytics
- 🔐 AI-assisted code review and security vulnerability analysis
- ⚙️ End-to-end ML pipelines, automated testing, and deployment
