## 🚀 About Me

I'm a **Data Science postgraduate student at GITAM University** passionate about engineering intelligent, secure, and scalable AI applications.

My work focuses on the intersection of **Agentic AI, Generative AI, and intelligent software engineering**. I enjoy designing systems where LLMs do more than generate text — they retrieve relevant information, reason through workflows, validate outputs, and recover from unreliable results.

I build practical AI applications ranging from **self-correcting RAG pipelines** to **natural-language-driven analytics systems**. I'm particularly interested in making LLM applications more reliable through structured outputs, evaluation, validation, and carefully designed agent workflows.

### 01 · NLQ Studio — Natural Language to SQL Analytics Engine

<p>
  <img src="https://img.shields.io/badge/Agentic%20AI-LangGraph-a5d8ff?style=for-the-badge" alt="Agentic AI"/>
  <img src="https://img.shields.io/badge/LLM-Groq-ffc9c9?style=for-the-badge" alt="Groq"/>
  <img src="https://img.shields.io/badge/Database-PostgreSQL-b2f2bb?style=for-the-badge" alt="PostgreSQL"/>
  <img src="https://img.shields.io/badge/UI-Streamlit-ffec99?style=for-the-badge" alt="Streamlit"/>
</p>

**Turning business questions into executable SQL and meaningful insights.**

NLQ Studio is an AI-powered analytics application that enables users to explore relational data using natural language instead of manually writing SQL queries.

**Key engineering contributions**

- Built a LangGraph-powered workflow that transforms natural-language questions into SQL queries and executes them against PostgreSQL.
- Implemented dynamic database schema introspection to discover tables, columns, primary keys, and foreign-key relationships while maintaining schema metadata.
- Developed SQL security guardrails using SQLGlot AST validation, read-only transactions, and least-privilege database access to reduce the risk of destructive queries.
- Used Pydantic structured outputs to organize analytical responses, KPI summaries, tabular data, and chart configurations.
- Integrated an interactive Streamlit interface for SQL inspection, query results, data visualizations, and natural-language explanations.

> 💡 **What this project demonstrates:** Agentic workflow design, database-aware reasoning, secure query execution, structured LLM outputs, and interactive AI analytics.

### 02 · CorrectRAG — Agentic RAG with Self-Correction

<p>
  <img src="https://img.shields.io/badge/RAG-Agentic-d0bfff?style=for-the-badge" alt="Agentic RAG"/>
  <img src="https://img.shields.io/badge/Orchestration-LangGraph-a5d8ff?style=for-the-badge" alt="LangGraph"/>
  <img src="https://img.shields.io/badge/Vector%20Store-ChromaDB-ffc9c9?style=for-the-badge" alt="ChromaDB"/>
  <img src="https://img.shields.io/badge/Evaluation-Pytest-b2f2bb?style=for-the-badge" alt="Pytest"/>
</p>

**Making retrieval-augmented generation more reliable through evaluation and corrective workflows.**

CorrectRAG combines ideas from **Corrective RAG (CRAG)** and **Self-Reflective RAG (Self-RAG)** to improve the relevance and grounding of generated answers.

**Key engineering contributions**

- Designed an agentic RAG workflow using LangGraph and LangChain, incorporating retrieval assessment and answer-quality checks.
- Integrated Google Gemini for LLM-based document relevance grading before answer generation.
- Added Tavily Web Search as a fallback when local retrieval returns insufficient or irrelevant context.
- Implemented self-correction loops using hallucination detection and answer relevance grading to identify responses that need improvement.
- Built persistent vector retrieval with ChromaDB and Hugging Face `all-MiniLM-L6-v2` embeddings.
- Incorporated LangSmith-ready tracing and Pytest-based validation to support observability and testing.

> 💡 **What this project demonstrates:** Retrieval evaluation, corrective workflows, semantic search, grounded generation, and LLM application reliability.

### 03 · AI Code Review & Security Analysis Agent

<p>
  <img src="https://img.shields.io/badge/Domain-AI%20for%20Software%20Engineering-a5d8ff?style=for-the-badge" alt="AI for Software Engineering"/>
  <img src="https://img.shields.io/badge/Workflow-Multi--Agent-d0bfff?style=for-the-badge" alt="Multi-agent workflow"/>
  <img src="https://img.shields.io/badge/Security-OWASP-ffc9c9?style=for-the-badge" alt="Security analysis"/>
</p>

**Automating code quality inspection, vulnerability analysis, and actionable remediation.**

This project focuses on a smart code inspection platform that analyzes submitted source code, identifies potential quality and security issues, and produces a consolidated review report.

**Core workflow**

- **Code Analysis Agent:** Identifies code smells, design issues, overly complex functions, and poor coding practices.
- **Security Vulnerability Agent:** Analyzes potential security weaknesses, including SQL injection, cross-site scripting (XSS), and hardcoded secrets.
- **Unified Findings:** Runs code-quality and security analysis in parallel and merges their findings into a consistent report.
- **Remediation Agent:** Generates actionable fix recommendations, corrected code examples, and best-practice explanations for individual findings.
- **PR Summary Agent:** Consolidates the analysis into a final review summary, including finding categories and severity classifications.
- **RAG-Based Assistance:** Supports user questions about reported findings and relevant coding or security best practices.

The intended application includes a Streamlit interface for source-code input and review results.

> 💡 **What this project demonstrates:** Multi-agent orchestration, parallel execution, structured findings, security-focused LLM workflows, remediation generation, and RAG-based explanations.
